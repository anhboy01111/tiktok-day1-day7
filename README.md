## ✨ Game Features
- **8 Arcade Neon Colors**: RED, ORANGE, YELLOW, GREEN, CYAN, BLUE, PURPLE, WHITE with custom synth audio feedback.
- **4 Difficulty Modes**: Novice (5 colors), Classic (6 colors), Advance (7 colors), Master (8 colors).
- **8 Guess Attempts**: Solve the secret 4-color pattern before security locks down!
- **Playable Everywhere**: Powered by React 19 + Vite and hosted on GitHub Pages.
